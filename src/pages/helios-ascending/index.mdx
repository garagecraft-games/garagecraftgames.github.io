## About

**Helios Ascending** is a twin-stick shooter that originated as a university project at [Trier University of Applied Sciences](https://www.hochschule-trier.de) during the **Winter Semester 2025/26**.

It is built on top of [**helios**](https://helios.garagecraft.games) — a custom C++23 game engine developed from first principles, emphasizing modern software engineering, ECS architecture, and a hand-rolled OpenGL rendering pipeline.

- [**Dev Blog: Exploratory Development of an ECS-based Game Engine**](https://thorsten.suckow-homberg.de/blog/exploratory-development-of-an-ecs-based-game-engine)
- [**helios engine**](https://helios.garagecraft.games)
